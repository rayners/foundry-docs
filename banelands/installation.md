# Installation

## Foundry Module Browser

1. Open **Configuration** → **Add-on Modules**
2. Click **Install Module**
3. Search for **BaneLands**
4. Click **Install**

## Manifest URL

1. Open **Configuration** → **Add-on Modules**
2. Click **Install Module**
3. Paste this URL into the Manifest URL field:
   ```
   https://github.com/rayners/fvtt-banelands/releases/latest/download/module.json
   ```
4. Click **Install**

## Enabling the Module

1. Open your world
2. Go to **Settings** → **Manage Modules**
3. Enable **BaneLands**
4. Click **Save Module Settings**

## Requirements

- Foundry VTT v13 or later
- Dragonbane game system v3.0.3 or later

## First-Time Setup

Once enabled, BaneLands automatically initializes consumables for new Dragonbane characters. Existing characters will have their consumables initialized the first time their sheet is opened.

Default starting dice:
- Food: D8
- Water: D8
- Arrows: D8
- Torches: D6

You can change these defaults in **Settings** → **Module Settings** → **BaneLands**.
